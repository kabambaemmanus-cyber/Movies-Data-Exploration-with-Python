# Movies Data Exploration with Python

## Overview
This project explores a dataset of movies using **Python (Pandas, Jupyter Notebook)**. The dataset includes attributes such as movie name, rating, genre, and release year.  

The goal is to perform exploratory data analysis (EDA) to uncover insights about movie ratings, genres, and trends over time.

---

## Tools & Technologies
- Python  
- Pandas for data handling  
- Jupyter Notebook for interactive exploration  
- Dataset: `movies.csv`
